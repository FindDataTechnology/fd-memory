智能体长期记忆服务

会话会结束，
记忆不结束。

永忆（YongYi）把一个 agent 过去知道的一切——笔记、交接、事实与经验——变成每回合都可召回的结构化知识。换一个会话、隔一个季度回来，不用重推背景。

5 分钟起跑 先看分层

在产底线：单进程、零外部依赖、内置 SQLite + FTS；任何车道失败都优雅降级——不 5xx、不中断会话。

记忆河 · live

    琥珀 = 新写入 · 青 = 语义召回 · 灰 = 接替退役

    01

    四层记忆 · L0 → L3

    不是一层记忆用力撑平，而是四层位各自归位、各司其职。写完立即可召回，召回之后由 supersede 决定谁才该被信。

    • L0 observations

      原始事件流。每一个 tool 调用、每一轮会话、每一次往返，都按原始时间戳落盘——不评估、不改写，是蒸馏的原料级原始素材。

    • L1 notes + handoffs

      亲笔记与跨成员交接。写后立即进入双维召回（query 相关 top-3 + 新近 top-5）。写后约 1 分钟被写触发蒸馏接上，约 2 分钟就成为可检索的 L2。

    • L2 facts + experiences

      蒸馏过的结构化知识。检索对全库页面打分（向量 + 字段加权），词面不重合而语义最近的页也清晰可达。

    • L3 profiles (roadmap)

      用户偏好画像。按 owner 聚合的跨项目偏好抽取，注入时提供「这个用户是谁」。当前处于路线图位置。

    02

    召回三维防护

    全向量检索解除关键词限流；字段加权保关键词；双维 note 保证新写进的均能检索到。

    向量 · 全库扫描

    semantic

    不再以「关键词召回的候选」为限。向量对全库页面逐张打分——词面不重合但语义最近的页也清晰可达，得分即召回秩。

    关键词 · 字段加权

    title ×3 / keys ×2 / body ×1

    慢 embed 时也一样稳：title 命中记 3 分、search_keys 记 2 分、body 记 1 分——标题命中的才是真主题，正文顺带提到的不加分。

    Note · 双维召回

    query ≤3 + recent ≤5

    新近不是唯一入口——相关才是。query 匹配的 note 排在最前，再由新近补齐到至多 5 条；两层合起来，旧 note 不靠新近度也能被召回。

    03

    接替 · supersede

    一件事改了？最新的结论是你该信的。旧版本保留可查，但读面永远只看到最新那一条。

    没有「哪个版本对」的分歧——被接替的旧版只用来审计与复盘；读面永远给最新一条结论。

    04

    5 分钟起跑

    CLI 发第一枚 bootstrap token，再用它发一枚人根 token，就能问记忆——全程不需要任何外部用户的 token。

    01

    装依赖并构建（Node ≥ 22.5）

    npm ci && npm run build

    02

    本地启动（内置 SQLite+FTS，零外部依赖）

    ./dist/index.js serve --port 4000 &
curl http://127.0.0.1:4000/healthz  # → {"status":"ok"}

    03

    发 bootstrap token（CLI 自举）

    ./dist/index.js token mint \
  --kind platform --namespace '*' \
  --label bootstrap

    04

    用它发一枚人根 token，问记忆

    curl -X POST localhost:4000/admin/mint \
  -H "authorization: Bearer $BOOT" \
  -d '{"namespace":"u/demo"}'
# person token → /digest
