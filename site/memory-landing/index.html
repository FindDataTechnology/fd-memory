Endpoints

所有请求走 Authorization: Bearer <token>；/healthz 除外，它公开只读。

# 健康检查 / health probe
GET  https://memory.finddatatech.cloud/healthz

# 平台接缝读面 / platform-seam digest
GET  https://memory.finddatatech.cloud/digest?q=...&k=5

# MCP（streamable-http）
POST https://memory.finddatatech.cloud/mcp   // JSON-RPC
